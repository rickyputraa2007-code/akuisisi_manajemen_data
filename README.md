## Struktur Folder
- `data/raw`: data mentah, tidak diubah
- `data/interim`: data sementara
- `data/processed`: data hasil pembersihan
- `notebooks`: notebook analisis
- `src`: kode program
- `docs`: dokumentasi
- `reports`: laporan hasil

## Menjalankan
Gunakan Python 3.11 atau versi lebih baru. Pasang dependensi dengan:
`pip install pandas numpy requests beautifulsoup4 openpyxl`

Kemudian jalankan `python akuisisi_manajemen_data.py`.
Ganti identitas pada README dan file Python sebelum dikumpulkan.
